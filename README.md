# Meedee

[打开钢琴练习室](https://samecho.github.io/Meedee/)

为 iPad 跟练而做的纯前端 MIDI 播放器。主界面只保留曲名、音符与键盘、进度、播放、速度、移调和循环。曲目导入与低频设置在菜单里。

## 功能

- 下落音符与采样钢琴、亮键同步；左手蓝色，右手杏色。
- 播放、暂停、拖动进度、前后跳转 5 秒。
- 0.25×–1.50× 调速，保持音高；最多升降 12 个半音。
- 按小节选 A–B 循环，或用当前位置设置端点。
- 本地导入 MIDI 并保存在当前浏览器；不上传文件。
- iPad 横屏、竖屏及桌面布局；全屏、可选 3 秒预备、离线缓存。
- 设备离开前台时自动暂停；设置保留在当前设备。

## 当前内置版本

**Canon in D — Lee Galloway 钢琴编曲，社区 MIDI 转录**。使用 SlappingRico 于 2013 年在钢琴瀑布流视频中提供的 MIDI，46 小节，1,031 个音符，约 3 分 01 秒（界面显示已过整秒为 3:00）。保留原文件的速度变化、音符、力度、时值与 CC64 踏板。

原文件把双手合在一条音轨。维护脚本与 Midi2Piano 于 2008 年提供的双手转录对齐，并检查新增段落和内声部，生成 511 个右手、520 个左手音符。较短参考仅用于分配双手，未替代完整源文件的音符。

这是一份署名明确的社区转录，不声称是演奏者官方 MIDI。来源与权利信息见 [CREDITS.md](CREDITS.md)。

## 本地运行

Node.js 22 或更新版本，无需安装依赖：

```sh
npm run dev
```

打开 `http://127.0.0.1:5173/`。所有资源随站点提供，不依赖运行时 CDN。GitHub Pages 工作流推送到 main 后先检查、再部署，兼容仓库子路径。

## 验证与重建

```sh
npm test
npm run check
node scripts/build-canon.mjs
```

源 MIDI 和双手分配记录保存在 assets/source/。测试检查所有源音符、速度事件、完整结尾、双手、移调、调速、暂停、跳转、踏板和循环边界。

Web Audio 的同一时钟驱动声音和画面，调速只改变事件时间，移调才改变音高。支持通常的 PPQ MIDI 0/1、变速、变拍号和 CC64；忽略打击乐。导入上限 8 MB、10 万个音符、6 小时；暂不支持 SMPTE 时间格式。
